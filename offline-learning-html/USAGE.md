# offline-learning-html 使用说明

> 版本：v2.0.1 ｜ 安装位置：`C:\Users\ouyan\.dsh\skills\offline-learning-html\`
> 交付形态：一个**单文件、离线、自包含**的 `.html`。

## 1. 名称与定位

`offline-learning-html`（离线交互学习 HTML）：把学习目标/知识点做成可交互、可离线、单文件的教学产品。它不是文档排版工具，也不是通用网站生成器。

## 2. 核心能力

- 单文件架构：CSS/JS/SVG/字体全部内嵌；禁止 CDN、外部库、远程图片/字体/API。
- 学习目标分析、知识结构、难度分级、交互机制选择。
- 交互沙盒：控制面板、实时反馈、预设场景、分步执行、仿真准确性声明。
- 测验：单选/多选/判断/填空/代码预测/计算/场景题 + 解析反馈。
- `localStorage` 进度保存、失败降级、JSON 导出/导入、重置、版本迁移。
- UI/UX、明暗主题、响应式、可访问性。
- 知识准确性、安全（避免 `eval`/不安全 `innerHTML`）、离线校验。
- 静态检查、功能测试、浏览器测试、严重度分级。

## 3. 适用任务

- 交互式教程、离线教育网站、概念可视化。
- 交互式技术演示、分步教程。
- 闪卡、测验/考试工具、自测系统。
- 单文件教学工具（断网可用、无需安装）。

## 4. 不适用任务

- 普通静态 Markdown 文档 → `knowledge-content-engine`。
- 需要后端/登录/在线数据库的网站。
- 需要真实硬件集成/在线服务的项目。
- 正式 DOCX/PPTX/PDF 排版 → `office` 系列。
- 开放式研究 → `research-engine`。

## 5. 调用与触发

- **自动**：出现“交互式教程/教育 Web 应用/概念可视化/离线学习页/单文件教学工具/模拟器/测验页”等意图时可加载。
- **显式**：说“用 offline-learning-html 做一个离线单文件页面”。
- 本 Skill 不调用其他 Skill；跨 Skill 交接按 `guides/handoff-contract.md`。

## 6. 推荐的自然语言请求

- “做一个离线单文件的 STM32 GPIO 配置模拟器，含 5 道题、解析和进度保存。”
- “把这份 C 指针讲义变成可交互页面，包含内存可视化和分步执行。”
- “做一个逻辑门真值表练习页，断网可用，支持深浅色。”

## 7. 所需输入

| 项 | 必填 | 说明 |
|---|---|---|
| 学习目标 | 是 | 学完能做到什么 |
| 受众/前置 | 是 | 初学者/有基础；需要先会什么 |
| 知识点 | 是 | 核心概念、难点、易错点 |
| 交互要求 | 否 | 可视化/仿真/分步/测验 |
| 题量/题型 | 否 | 默认 3–7 题 |
| 进度/数据 | 否 | 是否需要 localStorage、JSON 导入导出 |
| 输出路径 | 否 | 不指定时给建议文件名 |

来自 KCE 的任务可直接接收 `interaction-brief.md`（字段见 KCE USAGE）；缺 brief 时至少问目标、受众、知识点、交互。

## 8. 预期输出

- 一个完整 `.html` 文件（描述性文件名，不用 `index.html`）。
- 交付说明：用途、主要交互、打开方式、是否做过浏览器测试、已知限制。
- 若文件创建不可用：完整 HTML 源码（单代码块，不截断），并声明未生成文件。

## 9. 可复制提示词

```text
用 offline-learning-html 做一个单文件离线交互页。
主题：<...>；受众：<...>；学完能做到：<...>。
必须：概念讲解 + <可视化/分步/测验> + 进度保存 + 明暗主题 + 响应式 + 无外链。
题量：<3–7>；输出到 <路径>；如果没做浏览器实测，请在交付说明里明确写“未做浏览器实测”。
```

## 10. 典型场景

- C 指针/内存可视化。
- STM32 GPIO/寄存器模拟器。
- 电路/逻辑门/数学函数交互演示。
- 离线单词卡/考试自测。

## 11. 与其他 Skill 协作

| 对象 | 交接 |
|---|---|
| `knowledge-content-engine` | 接收 `interaction-brief.md`；KCE 负责知识结构与答案正确性，OFF 负责 HTML 实现/离线/交互测试 |
| `embedded-learning-mentor` | ELM 提供学习目标/练习；OFF 做页面；ELM 检查学习效果 |
| `project-orchestrator` | PO 定义验收；OFF 回传测试状态与限制 |
| `engineering-assistant` | 页面里的代码示例可由 EA 审查；OFF 不做代码工程交付 |

## 12. 常见错误与排障

| 现象 | 处理 |
|---|---|
| `file://` 下 localStorage 不稳定 | 必须 try/catch；失败时提示“自动保存不可用”，保留会话；提供导出 |
| 没有浏览器自动化 | 做静态检查 + 说明“未做浏览器实测”；不得声称已浏览器验证 |
| 外部依赖混入 | 检查 `<script src>`、`<link href>`、`url(http...)`、`@import`、远程字体；发现即删/内嵌 |
| 页面按钮无反应 | 检查事件绑定、元素 id 重复、函数未定义、控制台错误 |
| 测验答案错 | 逐题核对题干/选项/答案/解析；必要时回 KCE 复核知识点 |
| 文件被覆盖 | 写入前确认路径；已存在时先备份或改名，不静默覆盖 |
