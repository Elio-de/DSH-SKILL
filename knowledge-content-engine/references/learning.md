# 学习材料模式（M-LEARN）写作与检查

> 职责：定义学习者画像、学习目标、前置图、概念四要素、例子/类比、易混点、练习与答案、复习迁移、章节模板与教学法审查。
> 读取时机：S5–S6（B 模式）；S8 教学法审查；T-04～T-07 评审。
> 不重复：证据/引用见 `evidence.md`；术语/格式见 `consistency.md`。

## 1 学习者画像

| 字段 | 含义 | 缺失处理 |
|---|---|---|
| `stage` | 零基础 / 有相关基础 / 进阶 | 标 unknown + 假设 |
| `prerequisites` | 已掌握 / 未掌握 | 标 unknown + 假设 |
| `goal` | 学完会用来做什么 | 提问或假设 |
| `timeBudget` | 可用学习时间 | 默认"未限定" |
| `context` | 课堂 / 自学 / 工作中 | 默认自学 |
| `languageLevel` | 专业术语熟悉度 | 默认"初学者" |

**零基础规则**：不得直接使用未解释术语；术语首次出现给定义/对照；难点前置解释。

## 2 学习目标（Bloom）

| 层级 | 允许动词 | 禁止 |
|---|---|---|
| L1 记忆/理解 | 解释、描述、区分、概括、举例 | 了解、熟悉、掌握 |
| L2 应用/分析 | 实现、调试、比较、分析、选择、计算 | 理解（单独使用） |
| L3 综合/评价 | 设计、评估、优化、论证、排查 | 精通 |

- 每章 2–5 条；编号 `OBJ-CHxx-n`。
- 每条目标必须可测量，并映射 ≥1 个练习。
- 禁止"了解/熟悉"类不可测目标。

## 3 前置图

- 节点 = 概念/知识点；边 = 依赖（A 依赖 B = 先学 B）。
- 构建：从每章 `concepts[]` 与 `dependsOn[]` 抽取。
- 校验：无环（拓扑排序）；无悬空（前置存在或标"外部先修"）；无自环。
- 跨章依赖只能指向更早章节或明确"先修章节"。
- 失败：环 → 拆节点/调顺序；悬空 → 补章节或标先修。

## 4 概念四要素

每个核心概念（`concepts[].core=true`；未标注取每章前 3 个高频概念）必须含：

1. **定义**：可判定、无循环定义。
2. **原理或作用**：为什么存在、解决什么问题。
3. **例子或类比**：与定义一致，不引入错误暗示。
4. **边界与误区**：什么时候不适用、容易怎么错。

**规则**：只写定义不写原理 = 缺陷；定义循环/类比与事实冲突 = Blocker。

## 5 例子、类比与图示

- 每个抽象概念 ≥1 个具体例子；例子与练习难度递进。
- 类比标 `[类比]`，并写"在哪些方面不成立"。
- 图示优先 Mermaid 源码或 Markdown 表格；标注"源码，未渲染"。
- 不得用类比替代定义或作为技术依据。

## 6 易混点与误区

- 主题存在易混点 → ≥2 组对比（相同点、不同点、判别方法、常见误用）。
- 不存在 → 显式声明"未发现易混点"并给判断依据。
- 误区纠正必须给错误示例与正确写法。
- 只写"注意区分"而不给判别方法 = 缺陷。

## 7 练习与答案（默认包含）

**用户已确认：学习材料默认含完整练习。**

| 项 | 规则 |
|---|---|
| 覆盖 | 每个学习目标 ≥1 题（C1 亦然） |
| 难度 | 至少覆盖 2 档：基础 / 应用 / 综合 |
| 每题 | 题干、作答要求、答案、解析（为什么对、错在哪）、涉及知识点；**manifest 必填 `requirement`（作答要求）** |
| 开放题 | 给评分要点 |
| 一致性 | 答案与正文一致；不考未讲内容 |
| 分离 | 题目与答案分文件/分区，便于自测 |
| 例外 | 仅当用户**明确要求**"只要自测/不要练习/精简版"时，用 `selfCheck` 自测清单替代，并在交付说明声明 |

**答案质量**：解析不得只写"见正文"；答案完整率 100%；无答案题 = Blocker。

**profile 不得覆盖此默认**：`notes`/`roadmap`/`knowledge-map` 等 profile 默认同样含练习；只有用户显式要求精简时才可降为自测清单。

## 8 复习、自测与迁移

- 每章小结 3–5 条要点。
- 自测清单：能否独立完成某任务。
- 迁移任务：把知识用到新场景。
- 整份材料：复习计划或知识地图。
- 不得只做知识点罗列。

## 9 章节模板

```text
## 学习目标（2–5 条，动词开头）
## 前置提示（需要先会什么；可跳读路径）
## 概念讲解（定义/原理/作用/边界）
## 例子与类比（[类比] 标注）
## 易混点与误区（对比表 + 判别方法）
## 小结（3–5 条）
## 练习（默认 ≥1/目标；题干/要求/答案/解析）
## 延伸（与已学知识联系、后续用途）
```

- 每章至少 1 处"与已学知识的联系"和 1 处"后续会用到的地方"。
- 跨章引用可定位。

## 10 教学法审查（S8）

| 检查 | 判据 | 失败 |
|---|---|---|
| 认知负荷 | 单章新概念 ≤7；首次给定义与例子 | 回 S6 拆分 |
| 难度曲线 | 章内 L1→L2→L3 不倒退；章间允许螺旋复习（回访基础须标"复习"） | 回 S6 调整 |
| 目标-内容-练习对齐 | 每条目标有讲解位置 + ≥1 练习 | 回 S6 |
| 可读性 | 中文单句 >80 字须拆分；抽 10 段能指出主题句 | 回 S6 |
| 术语解释 | 零基础读者术语解释率 100%（抽查 20） | 补解释 |
| 简化标注 | 简化处 100% `[简化]` | 补标注 |
| 前置 | 无"未讲先用" | 补章节/前置 |

## 12 常见缺陷

| 缺陷 | 修复 |
|---|---|
| 跳步（未讲先用） | 补前置章节或调整顺序 |
| 只给定义 | 补原理/作用/例子/边界 |
| 目标不可测 | 改 Bloom 动词 |
| 练习与目标脱节 | 重写练习或补目标 |
| 有题无答案/解析 | 补答案与解析；否则 Blocker |
| 类比当证据 | 标 `[类比]` 并改为解释性文字 |
| 术语未解释 | 首次出现给定义/中英对照 |
| 为通俗牺牲准确 | 标 `[简化]` 并修正错误暗示 |

## 13 与知识体系整理（knowledge-map）

- 适用于"专业知识体系整理"：以结构、联系、索引为主；**练习默认仍包含**（每主题至少 1 个自测/练习），仅用户明确要求"只要体系/不要练习"时改为自测清单并声明。
- 交付：结构图（Mermaid 源码）、知识点索引、学习顺序建议、关键概念表。
- 不生成 `.xmind`；如需导图文件，交接 S15。
