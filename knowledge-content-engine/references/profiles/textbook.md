# textbook（学习教材）

## 适用

多章、系统化学习；需要章节目标、前置链、练习与复习；读者要按顺序学完。

## 教学要点

1. 全书结构：章 → 节 → 知识点；前置图
2. 每章：目标（2–5）→ 前置 → 概念 → 例子 → 易混点 → 小结 → 练习 → 延伸
3. 难度分级：L1 记忆/理解、L2 应用/分析、L3 综合/评价
4. 练习：默认每目标 ≥1 题；答案与解析分离
5. 复习：章末小结 + 阶段复习 + 综合练习
6. 术语表与索引
7. 跨章联系（每章 ≥1 处）

## 常见缺陷

- 章与章之间无前置关系
- 目标不可测
- 练习集中在章末但与目标不对应
- 无复习/综合任务
- 术语首次出现未解释

## 验收锚点

- 前置图无环无悬空
- 每章目标 2–5 且可测
- 目标-练习对齐 100%
- 答案完整 100%
- 难度曲线不倒退

## 默认参数

- 档位：C3（多章教材）
- 预算：C3（读取 50/核验 30/章节 20/轮次 3）
- 练习：默认含完整练习
- 需计划确认：是
