# report（技术研究报告 / 项目技术报告 / 技术分析报告）

## 适用

以研究结论、证据与局限为主；读者要判断可信度或据此决策。

## 骨架要点

1. 摘要（结论 + 可信度 + 关键限制）
2. 背景与目的
3. 范围与方法（数据来源、口径）
4. 分析（分主题）
5. 结论表（结论/依据/可信度/验证等级）
6. 争议与不确定性
7. 局限
8. 建议（标注 `[建议]`）
9. 参考与证据
10. 附录（证据表，C3）

## 必查维度（≥5）

- 结论有证据、可追溯
- 来源评级与独立性
- 数据口径与时间范围
- 反方证据/替代解释
- 不确定性披露
- 版本/时效
- 结论与建议分离

## 常见缺陷

- 结论超出证据
- 单一来源标高可信
- 隐藏冲突
- 无局限
- 把建议写成事实
- 数据无口径

## 验收锚点

- 断链 0
- 关键结论有来源
- 冲突/局限可见
- 结论与建议分离
- `asOf` 存在

## 默认参数

- 档位：C2（深度研究 C3）
- 预算：C2/C3
- 练习：不适用
- 可消费 S01 成果（只读）
