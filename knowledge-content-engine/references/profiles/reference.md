# reference（参考文档：API / 参数 / 命令）

## 适用

读者按名称查找信息；以条目、表格、索引为主，不要求线性阅读。

## 骨架要点

1. 文档信息 + 适用版本
2. 使用说明（如何查找）
3. 条目（按命名空间/模块分组）
4. 参数/字段/返回值/错误码表
5. 示例（最小可用）
6. 版本差异与废弃项
7. 索引（按字母/模块）
8. 参考与变更记录

## 必查维度（≥5）

- 每条目的完整签名/字段/类型
- 默认值、取值范围、单位
- 错误码与异常
- 适用版本与废弃标记
- 示例可运行性/验证状态
- 命名与大小写一致性

## 常见缺陷

- 条目缺默认值/类型
- 版本差异未标
- 错误码缺失
- 示例不可运行且未标 `untested`
- 同名条目歧义（无命名空间）

## 验收锚点

- 条目字段齐全
- 版本/废弃标记存在
- 错误码完整
- 示例状态标注
- 断链 0

## 默认参数

- 档位：C2
- 预算：C2（条目多时按模块分批）
- 练习：不适用
- 组织：条目化优先，叙事最少
