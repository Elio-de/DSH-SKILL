# 术语、编号、格式与一致性

> 职责：术语表管理、编号体系、交叉引用、Markdown 规范、图表/公式/代码块规范、一致性检查。
> 读取时机：S9；交付前；写作中遇到术语/编号问题时。
> 不重复：内容质量见 `quality.md`；技术写作规则见 `tech-doc.md`；教学规则见 `learning.md`。

## 1 术语表

每条：

| 字段 | 说明 |
|---|---|
| `term` | 规范术语 |
| `definition` | 可判定定义（不用被定义词解释自身） |
| `firstUse` | 首次出现位置（章节/段落） |
| `translation` | 英文对照（如适用） |
| `aliases[]` | 禁用别名（仅用于识别，不用于正文） |

**规则**：

- 同一概念全文一个术语（首次出现给中英对照除外）。
- 缩写首次出现给全称。
- 英文术语保留原文，首次给中文。
- 术语表覆盖抽查 20 个专业术语的 ≥95%。
- 发现漂移 → 缺陷，回 S6 统一。

## 2 编号体系

| 对象 | 格式 | 稳定性 |
|---|---|---|
| 章节 | `CH-##` | 稳定；结构调整需映射表 |
| 小节 | `§x.y` | 与标题层级一致 |
| 步骤 | 章节内编号列表 | 章节内稳定 |
| 表格/图 | `T-##` / `F-##` | 全文档唯一 |
| 断言 | `CL-##` | 全局唯一，不复用 |
| 来源 | `SRC-###` | 全局唯一 |
| 引用 | `CT-##` | 全局唯一 |
| 练习 | `EX-##` | 全局唯一 |
| 目标 | `OBJ-CHxx-n` | 章节内唯一 |
| 版本 | `vMAJOR.MINOR` | 文档级 |

**规则**：不跳号、不重号；修订后编号变化必须记录旧→新映射。

## 3 交叉引用

- 正文引用格式：`§3.2`、`[CL-03]`、`[SRC-002]`、`EX-05`、`CH-02`。
- 每个引用必须可解析；断链 0。
- 禁止"见上文/见后文"等不可定位引用；改为明确章节号。
- 转引标注"转引自"。

## 4 Markdown 规范

| 项 | 规则 |
|---|---|
| 标题 | 层级连续，不跳级（#→##→###）；≤4 层 |
| 代码块 | 标语言；长代码给用途 |
| 表格 | 有表头；列数一致 |
| 链接 | 有效；外链注明 |
| 图片 | 有 alt；来源标注 |
| HTML | 不用 HTML 布局代替结构 |
| 编码/换行 | UTF-8；统一换行 |
| 目录 | >10 章提供目录 |
| 锚点 | `<!-- CH-## -->` 保留为不可见注释（续写定位用） |

## 5 图表、公式与代码块

| 对象 | 规则 |
|---|---|
| 图 | 优先 Mermaid 源码（`.mmd` 或围栏）+ "源码，未渲染"；简单关系用表格 |
| 公式 | LaTeX；变量说明；关键推导给步骤 |
| 表格 | 表头/单位/来源；过宽可拆表 |
| 代码块 | 语言/用途/依赖/运行方式/验证状态 |
| 截图 | 仅辅助；不得作为唯一依据；标注来源 |

## 6 一致性检查清单（S9）

| 检查项 | 判据 | 失败动作 |
|---|---|---|
| 术语一致 | 同一概念单术语（首次对照除外） | 回 S6 |
| 术语覆盖 | 抽查 20 个术语覆盖 ≥95% | 补术语表 |
| 术语首现 | `firstUse` 指向"给出定义"的位置（不是首次出现） | 补定义/修正 firstUse |
| 编号唯一 | 重号 0 | 修正并记录 |
| 交叉引用 | 断链 0 | 修正 |
| 标题层级 | 不跳级 | 修正 |
| 代码块语言 | 100% 标注 | 修正 |
| 表格表头 | 100% | 修正 |
| 图表来源 | 100% 有源/说明 | 补源或降级 |
| 公式变量 | 关键公式变量有说明 | 补说明 |
| HTML 滥用 | 无结构性 HTML | 警告/修正 |
| 目录 | >10 章有目录 | 补目录 |

## 7 机械修正与记录

- 可当场修正：编号、链接、代码块语言、表头、目录、锚点。
- 必须回 S6：术语选择、结论表述、结构变化、简化标注。
- 所有修正写入 `review.defects[]`（before/after）。

## 8 与质量门禁的关系

- S9 产出的术语/编号/引用结果，S10 直接复用（SQ-04/05/06），不重复扫描。
- 仅当结果缺失或标"不适用"时补检。
- 断链 0、重号 0 是 G5 的硬条件。
- **正文断链由 S9 负责**（脚本 `validate_manifest.py` 只校验 manifest，不扫描 `main.md`）；S9 必须扫描正文 `[CL-##]`/`[SRC-###]`/`EX-##`/`§x.y`/`CH-##` 并与台账核对。

## 9 常见缺陷

| 缺陷 | 修复 |
|---|---|
| 同一概念两个术语 | 统一并更新术语表 |
| 术语表缺条目 | 补 definition/firstUse/translation |
| 编号跳号/重号 | 重排并记录映射 |
| 引用"见上文" | 改明确章节号 |
| 代码块无语言 | 补语言标识 |
| 图表无来源 | 补来源或标"示意图" |
| 公式变量未说明 | 补变量表 |
| 文档内 HTML 排版 | 改 Markdown 结构 |
