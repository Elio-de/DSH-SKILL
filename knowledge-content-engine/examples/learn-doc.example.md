## 2 地址与指针

### 2.1 学习目标

- [ ] OBJ-CH01-1 能解释地址与指针的关系（L1 理解）
- [ ] OBJ-CH01-2 能写出解引用表达式（L2 应用）

### 2.2 前置提示

先确认：变量有名字，也有内存地址；数组在内存中连续存放。

### 2.3 概念讲解

**指针**

- 定义：指针是存储地址的变量。
- 原理/作用：让程序间接访问内存，支持动态数据结构与函数间共享数据。
- 例子/类比：`int x = 1; int *p = &x;`。可以类比"门牌号"：`p` 存的是门牌号，`*p` 是去那个地址取东西（`[类比]`；类比的局限：真实内存还涉及类型与对齐）。
- 边界与误区：未初始化的指针不可解引用；指针类型决定解引用读取多少字节。

### 2.4 易混点

| 概念 A | 概念 B | 相同点 | 不同点 | 判别方法 |
|---|---|---|---|---|
| 指针 | 变量 | 都占内存 | 指针存地址，变量存值 | 看声明是否有 `*` |
| `&x` | `*p` | 都与地址有关 | `&` 取地址，`*` 解引用 | 看运算符位置与上下文 |

### 2.5 小结

1. 指针存地址，解引用访问值。
2. `&` 取地址，`*` 在表达式中解引用。
3. 未初始化指针不可解引用。

### 2.6 练习

**练习 1（基础）**：解释 `int *p = &x;` 中 `&` 与 `*` 的含义。

### 2.7 延伸

## 3 指针与数组

### 3.1 学习目标

- [ ] OBJ-CH02-1 能说明数组名与指针的异同（L2 应用）

### 3.2 概念讲解

**数组名退化**

- 定义：数组名在多数表达式中转换为首元素地址。
- 原理/作用：支持用指针算术遍历数组。
- 例子：`int a[3]; int *p = a;`。
- 边界：`sizeof(a)` 不退化；数组名不可赋值。

### 3.3 易混点

| 概念 A | 概念 B | 判别方法 |
|---|---|---|
| 数组名 | 指针 | 看是否可赋值、`sizeof` 结果 |

### 3.4 练习

**练习 2（应用）**：`sizeof(a)` 与 `sizeof(p)`（`p=a`）结果是否相同？
- 答案与解析：见 `answers.md` EX-02。
- 对应目标：OBJ-CH02-1。
