# 交付前自检（release）

> 用于"这一版可以交给别人/烧进板子/上线"之前。缺项不得宣布完成。

## 一、能构建、能运行

- [ ] 从**干净目录**按 README 的步骤能编译通过
- [ ] README 里的命令**实际复制执行过**，不是凭记忆写的
- [ ] 产物路径与 README 描述一致
- [ ] 首次运行有明确的"成功标志"（输出/灯/串口）

## 二、验证

- [ ] 单元/集成测试全绿（记录 N/M 与证据级别）
- [ ] 关键错误路径有用例（不只是 happy path）
- [ ] 编译器告警已清零或已显式说明原因
- [ ] 静态分析（`-fanalyzer` 等）结果已看并处理
- [ ] **硬件相关**：V5 由用户完成，交付物中注明"待硬件验证"的部分

## 三、资源与性能（嵌入式必查）

- [ ] `arm-none-eabi-size` 结果在预算内（Flash / RAM 有余量）
- [ ] 栈使用量评估过（`-fstack-usage`），留有余量
- [ ] 无动态内存（或已论证其安全性）
- [ ] 关键路径无阻塞调用（延时/忙等）
- [ ] 看门狗喂狗位置正确

## 四、文档

- [ ] README 含：环境要求、编译、运行、已知限制
- [ ] 接口文档与**真实签名**一致
- [ ] 变更记录（CHANGELOG）已更新
- [ ] 破坏性变更已写明迁移方式
- [ ] `.ea/` 知识库与当前代码一致（`stale_check.py` 无过期项）

## 五、安全与合规

- [ ] 无硬编码密钥/密码/Token
- [ ] 无调试后门、无注释掉的鉴权
- [ ] 输入校验覆盖外部数据入口
- [ ] 第三方代码/库的许可证已确认
