# 数据真实性与可复现性（M10）

> 职责：实测/估算区分、统计口径与单位、相关与因果、复现矩阵与 `reproLevel`。
> 适用：出现数据、指标、对比、方案性结论时。不适用：来源评级（`sources.md`）。

## 1. 数据种类（FR-044，`evidence[].dataKind` 必填）

| `dataKind` | 含义 | 典型 |
|---|---|---|
| `measured` | 实测 | 自己或引用方可复现的测量 |
| `estimated` | 估算 | 厂商估算、行业推算（须给方法与输入） |
| `modeled` | 建模/仿真 | 仿真结果、理论模型 |
| `reported` | 转述 | 媒体/报告转述他人数据 |

**硬规则**：不得把 `estimated`/`modeled` 表述为实测；估算必须写方法与输入；数据类证据缺 `dataKind` → 不得入链。

## 2. 统计口径与单位（FR-045）

比较前必须核对四项：

1. **口径**：含税/不含税、出货量/销售额、全球/区域、注册量/活跃量、平均值/中位数。
2. **单位**：USD/CNY、万台/台、GB/TB、含换算说明。
3. **时间范围**：统计期、发布滞后、是否年化。
4. **样本**：样本量、抽样方式、地域分布。

口径不一致 → 先换算或明确"不可比"；**不可比却强行对比 → 判失败**。对比表必须有脚注说明口径差异。

## 3. 相关与因果（FR-046，`conclusions[].causality`）

| 取值 | 条件 | 表述 |
|---|---|---|
| `causal` | 有机制证据或对照实验 | "A 导致 B" |
| `correlational` | 只有时间序列/横截面相关 | "A 与 B 相关/伴随" |
| `unclear` | 数据不足以判断 | "关系不明确" |

"因为 A 所以 B" 但只有相关性 → 判失败。常见陷阱：把行业增长与某技术普及同时发生当作因果；把招聘薪资与技能热度相关当作供需因果。

## 4. 复现矩阵（FR-066，`reproducibility`）

| 项 | 内容 |
|---|---|
| hardware | 型号/规格（CPU/内存/开发板/芯片） |
| software | 软件版本/构建号 |
| toolchain | 编译器/工具链版本（如 GCC 12.2、CUDA 12.1） |
| os | 操作系统与版本 |
| dependencies | 依赖清单与版本（锁文件） |
| parameters | 关键参数（编译选项、运行时配置、测试条件） |
| steps | 操作步骤（可被第三人照做） |
| expected | 预期结果（含允许偏差） |

缺失项标 `unknown` 并说明"对复现的影响"。**缺环境版本却声称"可复现"→ 判失败。**

## 5. 复现等级（FR-067，`conclusions[].reproLevel`）

| 等级 | 含义 | 允许的表述 |
|---|---|---|
| `theoretical` | 理论可行，未验证 | "理论上可行" |
| `documented` | 有文档可照做，本人未运行 | "按官方文档可复现" |
| `verified` | **我实际运行过并有记录** | "已实际验证" |

**只有存在实际运行记录才能用 `verified`**。不得因为"看起来能跑"就标 verified。

## 6. 数据表最小写法

```markdown
| 指标 | 数值 | dataKind | 口径 | 时间 | 来源 |
|---|---:|---|---|---|---|
| 中国嵌入式工程师平均月薪 | 18,000 CNY | reported | 招聘平台挂牌中位数，含年终折算 | 2026-H1 | [S-004] |
> 脚注：不同平台口径不同（是否含奖金/是否限一线城市），本表统一取"中位数、不含奖金"。
```

## 7. 常见误用与纠正

| 误用 | 纠正 |
|---|---|
| 把厂商典型值当实测 | 标 `reported`/`estimated`，并注明测试条件 |
| 用挂牌价当实际薪资 | 标 `reported` + 口径说明 + 降可信度 |
| 两个不同机构数据直接比大小 | 先列口径差异，再判断可比性 |
| 把时间序列相关写成因果 | 改 `correlational` 表述 |
| 说"可复现"但没写版本 | 补 `reproducibility` 或降 `reproLevel` |
| 用单一模型仿真结果下工程结论 | 标 `modeled` + 说明假设 |

## 8. 反例

- T07 中市场规模数据未标来源与口径 → 判失败。
- T02 中功耗数据混用"数据手册典型值"与"实测值"且未标注 → 判失败。
- "因为 A 所以 B" 却只有相关证据 → 判失败。
- 声称"已验证方案可行"但无运行记录 → FR-067 违规。
