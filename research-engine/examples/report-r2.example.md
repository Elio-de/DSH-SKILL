## 摘要

- HTTPS = HTTP + TLS：在传输层提供**加密、完整性校验与身份认证**三项能力，因此能防窃听、防篡改、防冒充…[C-01]
- 三项能力缺一不可；只有加密而没有证书校验时，仍可能被中间人攻击…[C-02]（可信度：中）
- 未发现重大冲突。

## 分析

### 子问题 1：HTTP 的安全缺口是什么

HTTP 明文传输：任何中间节点（路由器、代理、运营商）都可读取与修改报文；无身份验证，客户端无法确认服务端是否为真…[E-001]

> 证据：[E-001] ← 来源 [S-001]（S，tier 1）

### 子问题 2：TLS 提供了什么

TLS 在应用层与传输层之间提供三个性质：

1. **机密性**：握手协商出会话密钥，应用数据加密传输…[E-002]
2. **完整性**：AEAD 算法对每条记录做认证，篡改会导致校验失败…[E-003]
3. **身份认证**：服务端出示证书，客户端验证证书链是否锚定到受信任根…[E-004]

> 关键点：三项性质**共同**成立才构成"HTTPS 比 HTTP 安全"。若跳过证书校验（如某些客户端配置），则退化为"加密但不防冒充"…[C-02]
