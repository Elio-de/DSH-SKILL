# 硬件开发规范

> 本文件在**选型、画原理图、接线、上电、分析电气参数**时加载。软件问题去 `coding.md`，PCB 去 `pcb.md`，排障去 `debugging.md`。

## 0 安全前置（完整规则见 `safety.md` §3）

- 型号/参数不明 → **不给接线与上电方案**；标准问法见 `safety.md` §3.4。
- 任何可能损坏器件的操作，先说明风险并取得同意；上电必限流，从最低档开始。
- 不指导市电/高压；用户说"直接接 12V 试试" → 立刻停下，先算额定值。

## 1 设计流程

`需求 → 电源树 → 接口与电平 → 主控与外设 → 选型 → 原理图 → 核对 → 打样 → 上电验证`

每一步的产出都要能被下一步直接用；跳过电源树是最常见的返工原因。

## 2 电源设计

| 项 | 要做什么 |
|---|---|
| 输入保护 | 反接保护（二极管/PMOS）、过压（TVS）、浪涌、保险丝/自恢复 |
| 拓扑选择 | 压差小、电流小 → LDO；压差大、效率要求高 → DCDC |
| 电流预算 | 逐路列 typ/max，总电流留 ≥30% 裕量 |
| 压降与热 | LDO 功耗 `P=(Vin−Vout)×I`，算结温 `Tj=Ta+P×Rθja` |
| 纹波 | DCDC 开关纹波对 ADC/模拟的影响；必要时加 LC 或 LDO 二级 |
| 去耦 | 每个电源脚 0.1µF 就近 + 每路 10µF bulk；模拟电源另加磁珠/LC |
| 上电时序 | 多路电源的先后、使能脚、复位释放顺序 |
| 电池 | 保护板、充放电管理、低电检测、反接 |

**核对**：空载/满载电压、纹波、温升，都要有实测数字（V5 由用户提供）。

## 3 GPIO

- **电平**：查 DS 的 `Vih/Vil/Voh/Vol`；3.3V 器件能否接 5V 信号，要看该引脚是否 **5V tolerant**（不是整片都容忍）。
- **驱动能力**：`Ioh/Iol` 是极限，不是推荐值；驱动 LED 用三极管/MOS 或专用驱动。
- **LED 限流**：`R=(Vcc−Vf)/If`，例如 3.3V、Vf=2.0V、If=5mA → 260Ω 取 270Ω。
- **上下拉**：阻值影响功耗与上升沿；按键用内部上拉时注意消抖（RC 或软件）。
- **复用**：查数据手册的 AF 表；SWD 引脚被复用会导致再也连不上。
- **保护**：外部接口加 TVS/限流电阻，防止 ESD 与误接。

## 4 时钟系统

- **晶振**：负载电容 `CL=(C1×C2)/(C1+C2)+Cstray`，按手册 CL 反算 C1/C2；注意 ESR 与驱动能力。
- **内部 RC vs 外部晶振**：RC 精度差（±1% 起），串口/CAN 高波特率必须外部晶振。
- **PLL 与时钟树**：确认每路外设时钟上限，超频是最常见的"偶发死机"来源。
- **失效检测**：开启时钟安全系统（CSS）或外部看门狗，时钟停了要能复位。

## 5 复位电路

- RC 复位：阻容取值要保证复位脉宽大于手册要求；电容漏电会导致低温不复位。
- 专用复位芯片：电压监测更可靠，成本略高。
- **复位原因寄存器**：上电先读并记录，能区分"上电/看门狗/软件/欠压"。
- 调试口在复位后的行为要确认（有些芯片复位会关闭 SWD）。

## 6 数字电路

- 电平匹配：3.3V↔5V 用专用电平转换（双向/单向），不要用电阻分压凑合高速信号。
- 扇出与驱动：一个输出带多个输入时看输入电容与驱动电流。
- 传输延迟与建立/保持：高速总线要看时序余量，不是"能通就行"。
- 竞争冒险：组合逻辑加去抖/整形（施密特触发器）。
- 未用输入不要悬空（CMOS 悬空会振荡耗电）。

## 7 模拟电路

- **分压**：注意输入阻抗对被测电路的影响；ADC 采样时间要匹配源阻抗。
- **运放**：轨到轨、共模输入范围、增益带宽积、压摆率；单电源要偏置。
- **滤波**：RC 截止 `fc=1/(2πRC)`；抗混叠滤波要在采样率之前。
- **基准与噪声**：ADC 基准的精度决定绝对精度；模拟地与数字地分开走。
- **小信号**：远离时钟与电源；必要时屏蔽/包地。

## 8 信号完整性基础

- **上升沿决定带宽**：`BW≈0.35/tr`；线长超过波长 1/10 就要考虑传输线。
- **回流路径**：电流走最小回路，地平面断开 = 回流绕远 = 辐射与误码。
- **串扰**：平行走线越长越严重；拉开间距、加地线隔离、减少并行长度。
- **地弹**：大电流瞬变时地电位跳动，数字与模拟共地要谨慎。
- **端接**：长线/高速加串联或并联端接，按阻抗匹配。

## 9 接口电路

| 接口 | 关键点 |
|---|---|
| UART/TTL | 交叉连接（TX→RX）、共地、电平一致 |
| RS232/RS485 | 收发器、终端电阻、隔离、防雷 |
| I²C | 开漏 + 上拉；`Rp(max)≈tr/(0.8473×Cb)`，`Rp(min)` 由 `Vol/Iol` 决定（详见 UM10204） |
| SPI | 片选唯一、模式一致（CPOL/CPHA）、长线加串阻 |
| CAN | 收发器、两端 120Ω、共模电感、分支要短 |
| USB | 差分阻抗 90Ω、等长、ESD 保护 |
| 继电器/电机 | 续流二极管、隔离（光耦/驱动芯片）、独立电源 |

## 10 元器件选型

| 维度 | 要求 |
|---|---|
| 参数裕量 | 电压/电流/功率至少 1.5–2 倍裕量；温度按最坏情况 |
| 封装 | 能否手焊（0402 对新手不友好）、焊盘与钢网 |
| 供货 | 是否有货、交期、是否停产 |
| 替代 | 至少一个 pin-to-pin 或参数兼容的替代料 |
| 精度/温漂 | 采样电阻、基准、晶振要写清精度等级 |
| 成本 | 与 BOM 合并采购，但**不因便宜牺牲裕量** |

## 11 硬件连接

- 写**接线表**：`信号 | MCU 引脚 | 外设引脚 | 备注`，与最新原理图一致。
- 共地：所有模块必须共地；长距离/大电流考虑单点接地。
- 线径与压降：按电流选线径，长线算压降。
- 连接器：定义针序、防反接、锁扣；杜邦线不适合长期运行。
- 上电前检查：通断、短路、极性、电压档位、限流值。

## 12 电气参数分析（每次给方案都要过一遍）

| 参数 | 看哪里 | 常见错误 |
|---|---|---|
| 绝对最大额定 | DS 的 Absolute Maximum Ratings | 当成"推荐工作条件"用 |
| 推荐工作条件 | DS Recommended Operating Conditions | 忽略温度范围 |
| 输入/输出电平 | `Vih/Vil/Voh/Vol` | 3.3V 驱动 5V 器件不查阈值 |
| 驱动电流 | `Ioh/Iol`（注意测试条件） | 直接驱动继电器/LED |
| 功耗 | 各路电压×电流 + 静态电流 | 漏算 LDO 自身损耗 |
| 时序 | 建立/保持/上升时间/转换时间 | 只看功能不看余量 |

**降额**：电压 ≤80%、电流 ≤80%、功率 ≤70%（通用经验，具体按器件规范）。

## 13 上电检查清单

1. 万用表通断：电源与地是否短路。
2. 极性：电解电容、二极管、LED、连接器方向。
3. 电压档位：输入电压与板子标注一致。
4. 限流：电源限流设为预期电流的 1.2–1.5 倍。
5. 空载上电：先不接负载，测各路电压。
6. 分段验证：先电源，再主控，最后外设。
7. 记录：每路实测电压/电流/温度写进调试日志。

## 14 反模式

参数不明就给接线 ｜ 只算典型值不算最坏值 ｜ 忽略 LDO 发热 ｜ 3.3V 直连 5V 输入 ｜ 用 GPIO 直接驱动电机/继电器 ｜ 忘记共地 ｜ 去耦电容"象征性"放一颗 ｜ 晶振负载电容照抄不看 CL ｜ 上电不限流 ｜ 用"应该没事"回答电气问题。
