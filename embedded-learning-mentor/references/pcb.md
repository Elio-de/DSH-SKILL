# PCB 设计规范（立创EDA）

> 本文件在**原理图、布局布线、DRC、打样**时加载。电气原理去 `hardware.md`，代码去 `coding.md`。
> **工具说明**：本机装有立创EDA 专业版（`C:\软件\lceda-pro`），但 AI 不能操作 GUI；具体菜单入口随版本变化，**以你当前版本界面为准**，必要时先截图确认。本文件讲"为什么这么做"，不背菜单路径。

## 1 流程

`建工程 → 原理图 → ERC → 封装核对 → 转 PCB → 布局 → 布线 → 覆铜 → DRC → Gerber/BOM/坐标 → 打样 → 上电验证`

每步完成再进下一步；跳过 ERC 或 DRC 是返工的主要来源。

## 2 原理图

| 项 | 要求 |
|---|---|
| 电源树 | 每路电源画清来源、电压、电流；网络名统一（`+3V3`、`+5V`、`GND`） |
| 去耦 | 每颗 IC 的每个电源脚一颗 0.1µF，就近；每路一颗 10µF |
| 上拉 | I²C 的 SDA/SCL、复位、BOOT0、片选（按需） |
| 晶振 | 晶振 + 负载电容 + 可选串联电阻，靠近芯片 |
| 未用引脚 | 接地/上拉/悬空要**写明理由**，不能默认悬空 |
| 保护 | 外部接口加 ESD/TVS、限流电阻、保险丝 |
| 调试 | 留 SWD/UART 测试点、电源测试点、GND 测试点 |
| 标注 | 关键参数写在图旁（电压、电流、上拉阻值） |

**ERC 必须清零**；若有保留项，逐条写明"为什么可以忽略"。

## 3 器件与封装

- 封装与实物核对：引脚数、间距、焊盘尺寸、引脚 1 方向。
- 极性器件：二极管、电解电容、LED、连接器方向。
- 用 3D 预览检查干涉与高度。
- 替代料要确认封装兼容（同封装不同引脚定义 = 灾难）。
- 手焊优先选 0603 及以上；0402 需要经验与工具。

## 4 布局（先摆位，再布线）

| 原则 | 做法 |
|---|---|
| 分区 | 电源区 / 数字区 / 模拟区 / 接口区 / 射频区（若有）分开 |
| 晶振 | 紧贴芯片，下面不走线，周围包地 |
| 去耦 | 电容 → 过孔 → 地平面，路径越短越好 |
| 大电流 | 路径短而宽，先走电源再走信号 |
| 连接器 | 按结构位置放，注意插拔方向与应力 |
| 热 | 发热器件分散，远离温度敏感器件（晶振、传感器） |
| 天线 | 按模块手册留净空区，下方不走线不铺铜 |

## 5 布线

- **线宽载流**：1oz 外层 10mil ≈ 1A（温升 10℃ 经验值）；内层要降额约一半。大电流优先铺铜。
- **间距与电压**：低压信号常规 6/6mil；有高压时按爬电距离加间距。
- **回流路径**：信号线正下方要有完整地；跨分割是 EMI 与误码的常见原因。
- **差分对**：USB/CAN 等长、等距、阻抗匹配；不要跨分割。
- **时钟/高速**：尽量短、少过孔、包地；远离接口与电源。
- **模拟小信号**：远离时钟与 DCDC，走线短、包地、单点接地。
- **避免直角**：45° 或圆弧，减少阻抗突变（低频影响小，但养成习惯）。

## 6 电源与地平面

- **完整地平面优先**，不要随意分割；需要分割时（模拟/数字）说清回流路径。
- 双层板：底层尽量整片地，顶层走线与铺铜结合。
- 过孔缝合：地平面边界、晶振周围、连接器附近多打地过孔。
- 电源平面/粗线要能承载预算电流，并留裕量。

## 7 过孔

- 常规工艺：孔径 0.3mm、外径 0.6mm（以板厂能力为准）。
- 载流：大电流多打几个并联；散热焊盘多打过孔。
- 高速信号少换层；必须换层时旁边加回流地过孔。

## 8 线宽与间距（与板厂能力对齐）

| 项目 | 常规能力 | 说明 |
|---|---|---|
| 最小线宽/间距 | 6/6 mil | 嘉立创普通工艺；进阶 4/4 需加价 |
| 最小孔径 | 0.3 mm | 更小需确认工艺 |
| 阻焊桥 | 视间距 | 太近会连锡 |
| 阻抗控制 | 需注明 | USB/CAN 等按要求标注叠层与阻抗 |

选之前先看板厂**工艺能力表**，不要按"我想要"设计。

## 9 DRC

- 规则先设对：间距、线宽、孔径、丝印、焊盘环宽。
- 常见报错与处理：

| 报错 | 原因 | 处理 |
|---|---|---|
| 未连接 | 网络没连上/被覆铜隔离 | 补线或加过孔 |
| 间距违规 | 走线太近 | 移线或改规则（改规则要写理由） |
| 丝印压焊盘 | 位号放置 | 移位 |
| 孔环不足 | 孔径/外径不匹配 | 改过孔尺寸 |
| 孤岛铜 | 覆铜未连接 | 加过孔或删孤岛 |

**忽略任何 DRC 都必须写理由**，不能"全部忽略"了事。

## 10 制造文件

- **Gerber**：铜层、阻焊、丝印、钻孔、板框齐全；输出后逐层预览。
- **BOM**：型号、封装、位号、数量、替代料；注意"不贴"标记。
- **坐标文件**：贴片用；确认原点与旋转角度。
- **拼板/工艺边**：按板厂要求；邮票孔或 V-cut 选一种。
- **表面处理**：HASL 便宜、ENIG 平整适合细间距。
- 下单备注：阻抗、叠层、特殊工艺。

## 11 打样与上电

1. 收货先目检：划伤、连锡、缺件、丝印、板厚与工艺。
2. 上电检查与分段验证按 `hardware.md` §13 的清单执行（万用表测短路 → 限流 → 空载电压 → 再接负载）。
3. 每步记录实测值，异常立即断电。

## 12 立创EDA 操作要点（通用，不背菜单）

| 环节 | 要点 |
|---|---|
| 工程 | 一个项目一个工程；原理图与 PCB 关联 |
| 库 | 优先用官方库；自建封装必须核对尺寸与引脚 1 |
| 网络 | 用网络标签代替长连线；电源网络统一命名 |
| 转 PCB | 先确认所有封装已绑定，再导入 |
| 布局 | 先用飞线判断关系，再摆位；锁定关键器件 |
| 覆铜 | 设置间距与网络，检查孤岛 |
| 检查 | ERC/DRC 面板逐条过；导出前再跑一次 |
| 导出 | Gerber + BOM + 坐标，打包前逐层预览 |

具体按钮位置随版本变化；操作卡住时让你截图，我按界面指位置。
