## 2 命名规则

| 类型 | 规则 | 例 |
|---|---|---|
| 目录 | 两位序号_中文名 | `03_嵌入式技术` |
| 知识笔记 | 名词短语，不用序号 | `GPIO 输出模式.md`、`I2C 时序.md` |
| 学习日志 | `YYYY-MM-DD-主题.md` | `2026-11-20-GPIO 点灯.md` |
| 错误记录 | `ERR-三位序号-简述.md` | `ERR-001-开漏点不亮.md` |
| 项目档案 | `<项目名>/项目档案.md` | `05_项目实践/温控盒/项目档案.md` |
| 阶段总结 | `YYYY-MM-DD-阶段N-总结.md` | `2026-12-01-阶段1-总结.md` |

- 不用空格，用 `-` 或中文；不用"新建笔记1"这类无意义名。
- 一个主题一篇；内容超过 200 行再拆分，拆分后互链。

## 4 双链规则

- 知识之间：`[[GPIO 输出模式]]`、`[[I2C 时序]]`。
- 笔记 → 项目：`[[温控盒项目]]`；项目 → 笔记：`[[GPIO 输出模式]]`。
- 档案 → 知识：`[[GPIO 输出模式]]` 写在"关联知识"栏。
- 链接到已有手册：`[[00-01-学习路线与过关标准]]`、`[[学习路线与能力地图]]`（只链接，不复制）。
- **允许红链**（指向还没写的笔记），但要加 `（待建）` 标注，避免以后误以为已存在。
- 不链接到目录，只链接到笔记。

## 6 生命周期

`草稿（09 日志）→ 稳定（02/03/04）→ 被替代（标 superseded + 链接新笔记）→ 归档（08 或加 tag 状态/已归档）`

- **不删除旧笔记**：标 `> 已被 [[新笔记]] 替代（YYYY-MM-DD）`，保留历史。
- 内容过时但仍有参考价值：加 `状态/已归档`，不参与日常检索。
- 事实变化（器件改版、库升级）：更新正文 + 在文末写"修订记录"一行。

## 7 扩展规则

新增一级目录需同时满足：① 同一主题已有 ≥3 篇；② 现有目录放不下；③ 不会与 02/03 重叠。编号接续（`10_`、`11_`），不要插入打乱既有编号。新增后在本文件 §1 登记，并在 `99_模板/模板说明.md` 更新说明。

## 9 与记忆插件的边界

- Vault：详细笔记、项目文档、错误全文——**事实源**。
- 插件 Documents：可检索的**摘要与索引**，每条必须写 `source_paths` 和生成日期，允许过期，以 Vault 为准。
- 插件 Runtime：跨会话偏好，只放"怎么教"，不放学习内容。
- 同一结论两边都有时：**以 Vault 为准**，冲突处理见 `memory.md` §6。
