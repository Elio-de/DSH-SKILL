# 故障排查规范

> 本文件在**"不工作/报错/波形不对/收不到数据"**时加载。目标：用证据收敛，而不是"改改试试"。
> 硬件参数分析去 `hardware.md`；代码问题去 `coding.md`。

## 0 八步闭环（统一流程）

`证据收集 → 问题复现 → 提出假设 → 设计验证 → 定位原因 → 修复 → 回归测试 → 总结`

- 每一步都要有**可写下来的产出**；写不出来说明这步没做完。
- 不允许跳步：证据不足时提假设 = 猜；不回归就修 = 赌。

## 1 证据收集（按问题类型要）

| 问题类型 | 需要什么 | 缺了怎么办 |
|---|---|---|
| 编译/链接错误 | 完整报错、工具链版本、完整命令行、改了哪行 | 让他贴原始输出，不要转述 |
| 烧录失败 | CLI 完整输出、连接方式、目标型号、选项字节状态 | 先 `-l` 列出探针，确认连接 |
| 上电无反应 | 各路电源实测电压、复位电平、时钟、BOOT 电平 | 万用表逐点测，先不接外设 |
| 通信失败 | 波形/抓包、波特率、地址、上拉、共地 | 有逻辑分析仪就抓一帧；没有按 `tooling.md` §6 降级（换可观测点/让用户测） |
| 数据异常 | 采样率、基准、输入范围、滤波、标定 | 给一段原始数据，不要只给结论 |
| 偶发死机 | 复位原因寄存器、看门狗、栈水位、HardFault 现场 | 先让固件记录复位原因并打印 |
| 功耗偏高 | 各路电流、外设时钟、低功耗模式、漏电路径 | 分段断电测电流 |
| 板子不启动 | 原理图、PCB、BOM、焊接照片、上电顺序 | 对照 `pcb.md` §11 逐项过 |

**证据不足时的标准说法**：

> 目前只能确认：___（V2/V3）。
> 还缺：___（哪一项证据）。
> 下一步需要你提供：___（具体到命令/测量点/截图），我才能给结论。

**禁止**：把猜测写成结论；用"可能是硬件问题"结束对话。

## 2 问题复现

- **最小复现**：去掉无关功能，只留能触发问题的最小代码/最小接线。
- **频率**：每次 / 偶发 / 上电必现 / 运行一段时间后 / 特定温度电压下。
- **环境**：固件版本、硬件版本、供电、负载、最近一次改动。
- 不能复现时，先加**观测点**（日志、GPIO 翻转、计数器），不要盲改。

## 3 提出假设

- 最多 **3 个**，按可能性排序。
- 每个假设必须**可证伪**：写出"如果这个假设成立，应该观察到什么"。
- 每个假设配一个**最小实验**和一个**判据**。
- 反例："可能是硬件问题"——不可证伪，等于没说。
- 好假设示例："如果中断没进，PA5 翻转频率应为 0；如果进了但卡住，翻转一次后停。"（可测）

## 4 设计验证

- **一次只改一个变量**；改之前记录当前状态，能回退。
- **二分**：代码（注释一半）、硬件（换模块/换线/换板）、时间（加时间戳定位顺序）。
- **观测手段由弱到强**：

| 手段 | 适用 | 注意 |
|---|---|---|
| 日志/`printf` | 流程、状态 | 中断里可能阻塞、破坏时序 |
| GPIO 翻转 + 逻辑分析仪 | 时序、频率、中断 | 最推荐，开销小 |
| 示波器 | 电源、时钟、波形质量 | 注意探头接地 |
| 调试器断点 | 变量、调用栈 | 会改变时序，实时性问题慎用 |

- 每次实验记录：改了什么 → 观察到什么 → 支持/否定了哪个假设。

## 5 分层定位（顺序不能跳）

| 层 | 查什么 | 判据 |
|---|---|---|
| 0 安全 | 短路、极性、限流 | 上电前无短路 |
| 1 电源 | 各路电压、纹波、上电顺序 | 在 DS 范围内 |
| 2 时钟 | 晶振起振、时钟源选择、PLL | 频率与配置一致 |
| 3 复位 | NRST 电平、复位原因 | 不反复复位 |
| 4 BOOT | BOOT0/BOOT1 电平 | 启动模式正确 |
| 5 引脚 | 复用、上下拉、焊接 | 与原理图/手册一致 |
| 6 总线 | 上拉、地址、ACK、速率 | 有 ACK、波形干净 |
| 7 协议 | 帧格式、时序、CRC | 与规范逐字段对齐 |
| 8 应用 | 状态机、缓冲、并发 | 逻辑自洽 |

**结论必须能解释所有现象**；只解释一半，说明还没定位到根因。

## 6 修复

- 最小改动：一次只修一个原因。
- 可回退：改前备份/提交；不能回退的改动要格外谨慎。
- 修根因，不打补丁掩盖现象（例：加大延时"绕过"竞态 = 没修好）。
- 修完写清"为什么这样修"，方便回归与复用。

## 7 回归测试

- 原问题按原步骤复测。
- 受影响功能全跑一遍。
- **相邻功能**也要跑（改中断可能影响串口）。
- 边界与长时间运行：至少一次压力/持续运行。
- 回归结果写进 `05_项目实践/<名>/` 调试日志。

## 8 总结

- 根因一句话（机制层面）。
- 同类风险排查：还有哪里可能犯同样的错。
- 写进调试日志；如果暴露的是知识漏洞，进 `06_问题与故障记录/错误台账.md`（见 `assessment.md` §4）。
- 更新检查清单，避免下次再犯。

## 9 常见故障速查

| 现象 | 先查 | 常见根因 |
|---|---|---|
| 上电没反应 | 电源、复位、BOOT、晶振 | 电压不够、复位被拉低、BOOT 错 |
| 反复重启 | 复位原因、看门狗、电源跌落 | 喂狗太晚、LDO 过流、栈溢出 |
| 烧录连不上 | SWD 接线、BOOT、复位、读保护 | 引脚复用、低功耗模式、选项字节 |
| 串口乱码 | 波特率、时钟、共地、电平 | 时钟源错、误差累积 |
| I²C 无 ACK | 上拉、地址、供电、总线电容 | 上拉缺失、地址错、从机没电 |
| SPI 读回全 0/全 FF | 模式、片选、供电 | CPOL/CPHA 不匹配、CS 时序 |
| ADC 抖动 | 基准、源阻抗、采样时间、地 | 采样太快、模拟地不干净 |
| 中断不进 | NVIC、优先级分组、标志清除 | 没使能、被更高优先级挡住 |
| 偶发死机 | 栈、越界、野指针、看门狗 | 局部大数组、字符串溢出 |
| 功耗偏高 | 外设时钟、GPIO 浮空、低功耗模式 | 未用外设没关、引脚悬空 |

## 10 反模式

证据不足就下结论 ｜ 一次改五处 ｜ 用"重新烧一次"当实验 ｜ 只解释一半现象 ｜ 修了不回归 ｜ 把"好了"当"修好了" ｜ 把现象当根因 ｜ 不看复位原因 ｜ 用延时掩盖竞态 ｜ 让用户反复重试而不加观测点。
