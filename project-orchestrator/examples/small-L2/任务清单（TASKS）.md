## 2 字段口径

| 字段 | 填报要求 |
|---|---|
| 执行者 | 只能是：主 AI、专业 Skill、子代理、工作流、工具（如 py -3 自检脚本）、用户；不得写不存在的能力 |
| 审核者 | 必须 ≠ 执行者；无法独立审核时写「用户」或「无（已披露局限）」 |
| 覆盖 AC | 至少 1 条已定义的 AC；覆盖缺口会使规划质量定 D |
| DoD | 可验证：给数量阈值、断言或可抽查证据，禁止「基本完成」 |
| 估算 / 估算依据 | 人天 + 依据来源（历史均值 / 三点估算 / 折算）；无依据不得给数 |
| 写域 | 相对路径；并行任务之间不得重叠 |
| 执行提示词 | L2 内嵌本字段：13 要素压到 7 行（角色/背景/目标｜输入/上下文｜步骤｜约束/禁止｜输出/质量｜验收｜异常/汇报） |
| 完成日期 | 仅 Done 时填写；Done 必须有 `项目进度（PROGRESS）.md` 记录 |
| 外部转交 | 本示例全部由本地可用的主 AI 与子代理完成，无「外部 AI（人工转交）」任务；若后续需要，执行者枚举允许写该项 |

## 3 状态机（英文原样使用）

| 当前状态 | 允许迁移到 | 条件 |
|---|---|---|
| Pending | In Progress、Cancelled | 依赖已满足、写域无冲突 |
| In Progress | Review、Blocked、Cancelled | 输出物齐备后提交审核 |
| Blocked | In Progress、Cancelled | 阻塞原因已消除并有记录 |
| Review | Done、In Progress | 审核者确认 DoD 逐条满足才可 Done |
| Done | In Progress | 仅当存在对应 CH 条目（返工） |

- 「执行完成 ≠ 验收完成」：Done 只表示任务级完成，项目完成以 G4 为准。
