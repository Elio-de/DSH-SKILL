# 工作文档（示例）

> 本目录是 `examples/small-L2` 的过程证据目录，用于让示例档案自洽：TASKS 的产出与交付清单的证据位置都能在此找到实际文件。

## 文件用途

| 文件 | 产出任务 | 用途 |
|---|---|---|
| `文档清单.csv` | TK-001 | 8 篇源文档的唯一清单（路径/标题/类型/版本日期） |
| `元数据表.csv` | TK-002 | 5 字段元数据（标题/类型/日期/主题/摘要） |
| `主题归类表.csv` | TK-003 | 8 篇 → 6 主题的唯一主归属 |
| `主题判定规则.md` | TK-003 | 6 条主题定义与判定示例 |
| `check_index.py` | TK-006 | 索引/锚点/外链的自检脚本（只读校验） |
| `自检记录.md` | TK-006 | 断言结果与失败项处理 |
| `验收记录.md` | TK-007 | AC 逐条证据与结论 |

> 说明：这些是**示例数据**，用来说明 L2 档案的"过程证据"如何落盘；不含真实业务信息。
