# 主题判定规则（示例）

> 6 个主题；每篇文档必须且只能归入 1 个主主题。

| 主题 | 定义 | 判定示例 |
|---|---|---|
| 构建与发布 | 构建、流水线、发布与回滚 | CI 流水线接入说明 |
| 可观测性 | 日志、指标、追踪、告警配置 | 日志规范 v2 |
| 接口与数据 | 接口定义、错误码、数据库变更 | 数据库变更流程、接口错误码表 |
| 运维值班 | 值班、压测、故障处理、维护 | 值班手册、压测方案 |
| 安全与合规 | 安全基线、合规、审计 | 安全基线检查表 |
| 团队协作 | 上手、协作流程、角色职责 | 新人上手清单 |

判定顺序：先看标题关键词，再看正文首段；冲突时以"读者要做什么动作"为准。辅主题写在备注，不进索引主标签。
