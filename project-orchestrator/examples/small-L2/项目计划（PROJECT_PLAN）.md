- **口径（与 PQ-E9 唯一公式一致）**：分子 = 上表 M02–M09 与 M15–M17 估算工时合计 0.36 人天；分母 = 项目总估算工时 3.18 人天；M10–M12（档案/进度、风险、变更）视为执行任务内嵌开销，按执行工时 2.20 人天的 10% 计 0.22 人天，计入总估算但不计入分子。
- **总估算工时构成**：执行 2.20 + 内嵌 M10–M12 0.22 + 管理段 0.36 + 关键路径缓冲 0.40 = **3.18 人天**（逐项来源见 `任务清单（TASKS）.md` 的「估算」与「估算依据」列）。

- **超标处置**：若后续变更使占比超过 15%，优先合并门禁与精简档案模板，不压缩验收标准、不擅自升降档位。
