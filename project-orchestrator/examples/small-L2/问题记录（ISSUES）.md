## 2 类型与处置权限

| 类型 | 定义 | 处置权限 | 是否升级用户 |
|---|---|---|---|
| 缺陷 | 输出物不符合 DoD 或 AC | 退回整改并重检 | 影响验收时升级 |
| Issue | 已发生但可自行处理的偏差 | 自助处理 + 记录 | 否（记录即可） |
| Blocker | 阻塞任务推进，无法自行解除 | 先给方案与影响 | 是（超过 1 天必升级） |
| 返工 | Done 后发现需重做 | 建 CH 条目后回 In Progress | 影响里程碑时升级 |
| 质量让步 | 需降低标准才能继续 | 禁止自行决定 | 是（用户书面同意） |

- 本项目 2 条均为可在任务内自行处置的类型（Issue / 缺陷），未触发升级；未发生 Blocker，未发生质量让步。

## 3 处置流程

1. 记录现象与影响（对象、时间、证据）→ 2. 判定类型与权限级别 → 3. 给处置动作与责任人 → 4. 执行并留证据 → 5. 复核是否消除 → 6. 关闭并写关闭依据。
- 关闭前验证：现象不再出现、受影响任务已重检、相关档案已更新（IS-001 → AC-009 复跑通过；IS-002 → AC-005/AC-007 复测通过）。
- 不可逆处置（删除、覆盖、外发、批量改写）必须先获授权并备份；本项目未执行不可逆操作。
