## 2 记录要求

| 要求 | 说明 |
|---|---|
| 谁决策 | 目标/范围/验收口径由用户决定；AI 建议必须标注「建议」并等待确认，本项目 6 条决策均由用户拍板 |
| 可追溯 | 背景写清约束与证据（CH 条目、实测结论），不写「因为更好」 |
| 影响面 | 每条决策列出受影响 ID，供 `变更记录（CHANGELOG）.md` 交叉引用 |
| 不可覆盖 | 已生效决策只追加不改写；与档案冲突时以最新决策为准并同步修正档案 |
| 权限边界 | 中风险先给方案与影响；高风险及时报告；极高风险暂停等用户决定 |

## 4 决策与变更的联动

- 决策导致计划变化 → 必须建 CH 条目并写明影响 ID（D-002 → CH-002；D-003 → CH-001，均已执行）。
- 决策导致需求变化 → 先更新 `项目需求（REQUIREMENTS）.md`，再按 Q2/Q8 重做规划质量重检（已执行，PASS）。
- 决策与档案冲突 → 以最新决策为准并同步修正，禁止双口径并存。
