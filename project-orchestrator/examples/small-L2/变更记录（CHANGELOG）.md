## 3 变更流程

1. 提出申请（写清改什么、为什么）→ 2. 影响分析（RQ/AC/TK/MS/DL 全链 + 时间/成本）→ 3. 判定权限级别 → 4. 用户确认（如需要）→ 5. 建 CH 条目 → 6. 更新受影响档案 → 7. 重检（S4 规划质量 / G3 里程碑）→ 8. 在 `项目进度（PROGRESS）.md` 追加记录。
